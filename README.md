# 🌾 AgroAssist — Smart Crop Recommendation System

> AgroAssist is a machine-learning-powered crop recommendation system that helps farmers identify the most suitable crop based on soil nutrients and environmental conditions.

The application uses a **Random Forest Classifier** and an interactive **Streamlit** web interface to recommend crops based on seven important parameters: Nitrogen, Phosphorus, Potassium, Temperature, Humidity, pH, and Rainfall.

---

## 📌 Overview

Choosing the right crop is an important decision in agriculture. Crop suitability depends on several factors, including soil nutrient levels, temperature, humidity, soil pH, and rainfall.

AgroAssist analyzes these parameters using machine learning and predicts the most suitable crop for the given conditions.

---

## ✨ Features

- 🌱 Crop recommendation using Machine Learning
- 🤖 Random Forest classification model
- 🧪 Soil nutrient analysis
- 🌦️ Environmental condition analysis
- 🖥️ Interactive Streamlit web application
- 📊 Exploratory Data Analysis
- 📈 Machine Learning model evaluation
- ⚡ Fast crop prediction

---

## 🧾 Input Parameters

| Parameter | Description | Unit |
|-----------|-------------|------|
| **N** | Nitrogen content in soil | Value |
| **P** | Phosphorus content in soil | Value |
| **K** | Potassium content in soil | Value |
| **Temperature** | Environmental temperature | °C |
| **Humidity** | Relative humidity | % |
| **pH** | Soil acidity/alkalinity | pH |
| **Rainfall** | Rainfall amount | mm |
